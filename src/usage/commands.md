# Commands

> NOTE: There aren't many commands at the moment. If you have any ideas, suggest them in the [Discord server](https://discord.com/invite/5qzrB98sBA).

## Minecraft

All of the following subcommands are prefixed by `/dissonance `

- `link`: Generates a code to link your Discord and Minecraft account. This does nothing if the Dissonance whitelist is enabled.
- `unlink`: Removes the link between your Discord and Minecraft account. This will kick you from the game if the Dissonance whitelist is enabled, to allow the user to relink with a different account.
- `purge <count>`: Removes `<count>` messages from the output channel; this is mainly a debug command but can be helpful if there is an unsavory conversation that needs to be removed quickly.

## Discord

- `/link <code>`: Takes in a `<code>` and links the Minecraft account that generated it to the Discord account running the command.
- `/unlink`: Removes the link between your Discord and Minecraft account.
