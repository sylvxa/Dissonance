# Permissions

- `dissonance.link`: Allows users to use the `/link` command (`true` by default)
- `dissonance.unlink`: Allows users to use the `/unlink` command (`true` by default)
- `dissonance.purge` Allows users to use the `/purge <message count>` command (`false` by default)

> NOTE: In the future, some permissions will also affect users on Discord too.
